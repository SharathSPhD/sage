# Contributing

This is currently a single-PI research codebase built with agent assistance. The rules that bind all contributors, human or agent, live in the repo: root `CLAUDE.md` (invariants), `gates/` (what "done" means), `memory/decisions.md` (why things are the way they are). TDD is non-negotiable; a unit closes on domain validation, not green tests; `import strataq`, never `import sage`.
