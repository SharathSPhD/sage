\begin{abstract}
\noindent
\strataq{} is an open-source JAX library for logit quantal response equilibrium
(QRE) analysis and for three things routinely needed \emph{after} an equilibrium
that no existing package provides: the exact derivative of the equilibrium with
respect to payoffs (the strategic resolvent $\chieq=(I-SB)^{-1}S$, which no
solver exposes); the Candogan--Menache--Ozdaglar--Parrilo potential/harmonic
decomposition, of which no implementation exists on any package index fifteen
years after publication; and the non-equilibrium thermodynamics of the revision
dynamics --- currents and entropy production of the joint-profile Glauber chain
--- which existing irreversibility estimators cannot compute because they take a
scalar series and have no concept of an agent. A fourth gap is closed by a
packaged estimation workflow with named intervals, documented as missing by the
reference solver's own maintainers. On top sits a problem-oriented API (pricing,
auction, routing, allocation, electricity, repeated, evolutionary and
extensive-form problems), a one-call \texttt{diagnose()} whose refusals are
returned as bounds, and publication figures on a shared palette.
The paper's argument is its calibration table: fourteen readings on systems whose
correct answer is fixed by an analytic identity or an external oracle, each
mapped to a committed artifact that regenerates from a recorded seed. The
reciprocity defect reads $\le 8.9\times10^{-17}$ on exact potential games and
$5.6\times10^{-17}$ on a real road network; the equilibrium derivative matches
central finite differences to $1.3\times10^{-8}$ and an independent
implicit-differentiation path to $5.6\times10^{-17}$; fixed-$\lambda$ profiles
match \texttt{pygambit}'s homotopy to $1.2\times10^{-9}$, and the agent-QRE
solver matches \texttt{pygambit}'s extensive-form solver on four classic trees
inside the library's $10^{-8}$ oracle tolerance. We describe the evidence
discipline the project runs on, including the release-integrity failure (F-0018)
in which 23 in-repo gates were green while every solver call in the shipped wheel
raised \texttt{FileNotFoundError}, and the tests that exist because of it.
Limitations are stated in the same voice: the exact dynamics layer is dense and
small-game only, the product surface above the gated instrument layer is tested
but not yet gated, the extensive-form oracle checks are skippable, and the public
API is broader than \texttt{\_\_all\_\_} documents.
\end{abstract}

\noindent\textbf{Keywords:} quantal response equilibrium; logit; comparative
statics; potential games; Hodge decomposition; entropy production; JAX;
research software

\section*{Availability}
\strataq{} is Apache-2.0 and on PyPI (\texttt{pip install strataq}); the
repository (\url{https://github.com/SharathSPhD/sage}) carries the library, the
experiments, the gate records, the claim ledger and the findings log.
Dominick's-derived artifacts are CC-BY-NC-4.0 and ride with the data, never
with the package.
