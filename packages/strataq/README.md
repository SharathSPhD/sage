# strataq

The SAGE library: Nash and quantal-response equilibria, potential and non-potential games, entropy-regularised response, and non-equilibrium strategic dynamics, in JAX.

```python
import strataq  # never `import sage` — SageMath owns that name
```

Pre-alpha. Not yet published to PyPI; publication waits for Stage 1 gates. See the [SAGE monorepo](https://github.com/SharathSPhD/sage) for the research programme, gates, and documentation.
